# รายงาน R01–R12 — นิยาม ขอบเขต และรูปแบบไฟล์

ทุกรายงานคำนวณที่ server ตามสิทธิ์ของผู้ขอ **ณ เวลาที่สร้าง** และใช้ projection `DailyAttendance` กับฟังก์ชันนับ (`tally`) ชุดเดียวกับหน้า "ภาพรวมวันนี้"
(`src/application/services/daily-summary.js`) — โค้ดนิยามรายงานอยู่ที่ `src/application/reports/definitions.js`

## รูปแบบ

| รูปแบบ | สร้างอย่างไร | วันที่ | จำกัดแถว |
|---|---|---|---|
| บนจอ | `report.preview` (ไม่บันทึกเป็นฉบับ) | พ.ศ. | 500 (แสดงว่าตัด) |
| CSV | UTF-8 พร้อม BOM, CRLF, RFC 4180; ข้อความที่ขึ้นต้น `= + - @ TAB CR` ถูกนำหน้าด้วย `'` | ค.ศ. `YYYY-MM-DD HH:MM` (เวลาท้องถิ่น) | 100,000 |
| XLSX | Google Sheet ชั่วคราว (คอลัมน์ข้อความเป็น Plain text) → Drive API export เป็น .xlsx จริง → ลบไฟล์ชั่วคราว — **ไม่ใช่ CSV ที่เปลี่ยนนามสกุล** | ค.ศ. | 50,000 |
| PDF | สำเนาแม่แบบ Google Docs (A4, หัวกระดาษโรงเรียน) → ตาราง + ปักหมุดแถวหัวตาราง (`pinTableHeaderRows`) ให้ซ้ำทุกหน้า → `getAs('application/pdf')` → ลบไฟล์ชั่วคราว; ผู้จัดทำ เวลาออกรายงาน ช่องลงนาม (`report.signature_lines`) | พ.ศ. | 2,000 |

- เลขหน้า: แทรกครั้งเดียวที่ footer ของแม่แบบ (INSTALL_GAS_TH) — Apps Script/Docs API ไม่มีคำสั่งแทรกเลขหน้า
- ฟอนต์: แม่แบบตั้ง `Sarabun` (Google Fonts) — ตรวจผล PDF ภาษาไทยในการทดสอบรับรอง
- ไฟล์ (CSV/XLSX/PDF) สร้างเป็นงานเบื้องหลัง เก็บเป็นไฟล์แนบประเภทรายงานในโฟลเดอร์ส่วนตัว ดาวน์โหลดผ่าน RPC ที่ตรวจสิทธิ์และ checksum ทุกครั้ง (audit) ไม่มีลิงก์สาธารณะ
- แต่ละฉบับเก็บ ตัวกรอง, `as_of`, schema version, เวอร์ชันกฎที่ใช้ และผู้สร้าง — ใช้อธิบายความต่างหลังมีการแก้ไขข้อมูล
- **ล็อก** (ผู้มีสิทธิ์ report.lock): ฉบับทางการ ไม่เปลี่ยน; "สร้างฉบับใหม่" ได้ revision ใหม่ ฉบับเดิมเป็น "ถูกแทนที่" แต่ยังดาวน์โหลดได้
- เวลาและขนาดบน Apps Script จริงยังไม่ได้วัด (การทดสอบรันบน emulator) — วัดใน UAT ก่อนกำหนดขีดจำกัดสุดท้าย
