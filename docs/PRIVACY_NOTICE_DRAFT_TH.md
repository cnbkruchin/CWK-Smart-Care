# (ร่าง) ประกาศความเป็นส่วนตัว — ระบบ CWK Smart Care

> **ร่างเพื่อให้โรงเรียนพิจารณา ยังไม่ใช่ประกาศที่มีผล** — โรงเรียนต้องตรวจทาน ปรับให้ตรงนโยบาย/ระเบียบที่ใช้จริง
> และขอความเห็นผู้รับผิดชอบด้านข้อมูลส่วนบุคคลก่อนประกาศ การมีประกาศหรือ checkbox **ไม่ได้ทำให้ระบบ "ผ่าน PDPA"**
> ข้อความในวงเล็บ […] คือส่วนที่โรงเรียนต้องกรอก เวอร์ชันประกาศที่ใช้งานบันทึกใน Settings `privacy.notice_version`

## 1. ผู้ควบคุมข้อมูลและช่องทางติดต่อ

[ชื่อโรงเรียน] [ที่อยู่] — ผู้รับผิดชอบ: [ตำแหน่ง/หน่วยงาน] อีเมล [……] โทร [……]

## 2. วัตถุประสงค์ของการใช้ข้อมูล

1. บันทึกการมาเรียน การมาสาย และการเช็กชื่อประจำวัน
2. รับและพิจารณาการลาของนักเรียน
3. ติดตาม ดูแล และช่วยเหลือนักเรียนตามหน้าที่ของโรงเรียน (เรื่องติดตาม การติดต่อผู้ปกครอง นัดหมาย)
4. แจ้งข้อมูลที่เกี่ยวข้องกับนักเรียนแก่ผู้ปกครองที่โรงเรียนยืนยันความสัมพันธ์แล้ว (ในแอป อีเมล และ LINE เมื่อผู้ปกครองเชื่อมบัญชีเอง)
5. จัดทำรายงานภายในของโรงเรียนและตรวจสอบย้อนหลัง (audit)
6. ดูแลความปลอดภัย สำรองข้อมูล และกู้คืนระบบ

ระบบ**ไม่**ใช้ข้อมูลเพื่อตัดสินนิสัย ความผิด หรือบทลงโทษโดยอัตโนมัติ เกณฑ์ติดตามมีไว้ให้ครูพิจารณาดูแลเท่านั้น

## 3. ข้อมูลที่เก็บ

| กลุ่ม | ตัวอย่าง |
|---|---|
| นักเรียน | รหัส ชื่อ-สกุล ชื่อเล่น เพศ วันเกิด (ถ้ามี) ห้อง/ประวัติห้อง รูปถ่าย (ถ้าโรงเรียนใช้) |
| ผู้ปกครอง | ชื่อ ความสัมพันธ์ ช่องทางติดต่อ (โทรศัพท์ อีเมล) บัญชี LINE ที่ผู้ปกครองเชื่อมเอง |
| การมาเรียน | เวลามาถึง จุดลงเวลา ผลเช็กชื่อ การยืนยันขาด ข้อยกเว้น การแก้ไขพร้อมเหตุผล |
| การลา | ประเภท ช่วงวัน เหตุผล เอกสารแนบ (เช่น ใบรับรองแพทย์ — **ข้อมูลอ่อนไหว** เห็นเฉพาะผู้มีสิทธิ์ และทุกการเปิดอ่านถูกบันทึก) |
| การติดตาม | เรื่องติดตาม บันทึกการติดต่อ นัดหมาย ข้อความที่ผู้ปกครองส่งถึงโรงเรียนผ่าน LINE (เฉพาะข้อความตัวอักษร) |
| บัญชีผู้ใช้ | อีเมลที่ใช้เข้าสู่ระบบ บทบาท ประวัติการทำรายการ (audit) |

## 4. ผู้ที่เข้าถึงข้อมูล

ตามบทบาทที่โรงเรียนกำหนด (PERMISSIONS.md) เช่น ครูที่ปรึกษาเห็นเฉพาะห้องของตน ผู้ปกครองเห็นเฉพาะบุตรหลานที่โรงเรียนยืนยันแล้ว
ครูเวรหน้าประตูเห็นเพียงข้อมูลระบุตัว — ผู้ให้บริการที่เกี่ยวข้อง: Google (Workspace/Apps Script/Drive/Firebase/Cloud Run), LINE (เมื่อผู้ปกครองเลือกใช้) [โรงเรียนระบุสัญญา/ข้อตกลงที่ใช้]

## 5. ระยะเวลาเก็บ

[โรงเรียนกำหนด — ดูค่าเริ่มต้นใน docs/OPERATIONS_TH.md §5 และ DATA_DICTIONARY] บันทึกระบบบางประเภทล้างตามระยะเก็บ;
ข้อมูลนักเรียน/การมาเรียน/การลา/การติดตาม ไม่ลบอัตโนมัติจนกว่าโรงเรียนจะอนุมัตินโยบายการลบ สำเนาสำรองเก็บ [30] วัน

## 6. สิทธิของเจ้าของข้อมูล

ขอเข้าถึง ขอสำเนา ขอแก้ไขข้อมูลที่ไม่ถูกต้อง (ในระบบ: "ขอแก้ไขข้อมูลการมาเรียน" ส่งให้ครูที่ปรึกษาพิจารณา) คัดค้าน หรือขอให้ลบ/ระงับการใช้ตามที่กฎหมายและระเบียบกำหนด — ติดต่อ [ช่องทาง]
ยกเลิกการรับแจ้งเตือนทาง LINE ได้เองในหน้า "การแจ้งเตือน" หรือเลิกติดตาม LINE OA ของโรงเรียน

## 7. ความปลอดภัย

การเข้าถึงตามบทบาทที่ตรวจที่ server ทุกครั้ง, ไฟล์และสำเนาสำรองไม่แชร์แบบใครมีลิงก์ก็เปิดได้, บันทึกการแก้ไขและการเปิดเอกสารสำคัญ — รายละเอียดใน THREAT_MODEL.md
