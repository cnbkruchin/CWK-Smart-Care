# คู่มือใช้งานประจำวัน — CWK Smart Care (ชุดที่ 3)

> ฉบับสำหรับทดสอบ (DEV/STAGING) ใช้ข้อมูลสังเคราะห์เท่านั้น ค่ากฎทั้งหมด (เวลาเริ่มสาย เส้นทางอนุมัติ ฯลฯ) เป็น **ค่าตัวอย่าง**
> จนกว่าโรงเรียนจะกำหนดค่าจริงในหน้า "ตั้งค่า" — หน้า "ภาพรวมวันนี้" จะเตือนเมื่อกฎยังเป็นค่าตัวอย่าง

## เมนูตามบทบาท

| เมนู | ใครเห็น (ตามสิทธิ์ใน PERMISSIONS.md) | ใช้ทำอะไร |
|---|---|---|
| ภาพรวมวันนี้ | ผู้มีสิทธิ์ดูการมาเรียน (ตามขอบเขต) | ตัวเลขวันนี้ ห้องที่ยังไม่เช็กชื่อ งานรอตรวจสอบ |
| ลงเวลาหน้าประตู | ครูเวร/เจ้าหน้าที่ประตู/กิจการนักเรียน | สแกนบัตรหรือพิมพ์รหัส → ตรวจหน้า → Enter บันทึก |
| เช็กชื่อประจำวัน | ครูที่ปรึกษา (ห้องตนเอง), กิจการนักเรียน | ระบุเฉพาะนักเรียนที่ไม่ได้ "มา" แล้วส่ง; ยืนยันขาดรายคน |
| แจ้งลา | ผู้ปกครอง นักเรียน ครูที่ปรึกษา กิจการนักเรียน | ยื่นใบลา ดูสถานะ ถอน/ขอยกเลิก/แก้ไขที่ถูกส่งกลับ |
| พิจารณาใบลา | ผู้พิจารณาตามเส้นทาง, ผู้ปกครอง (ยืนยันใบลาที่นักเรียนยื่น) | อนุมัติ/อนุมัติบางช่วง/ไม่อนุมัติ/ส่งกลับ/พิจารณาการยกเลิก |
| ประวัตินักเรียน | เปิดจากรายชื่อนักเรียน (ตามสิทธิ์) | สถานะวันนี้ สถิติ ไทม์ไลน์ ผู้ปกครอง (กดโทรได้) แก้ไข/ขอแก้ไขข้อมูล |

การซ่อนเมนูไม่ใช่การควบคุมความปลอดภัย — เซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำขอ

## 1. ลงเวลาหน้าประตู

1. เลือก **จุดลงเวลา** (ระบบจำไว้เฉพาะแท็บนี้)
2. สแกนบัตร (เครื่องสแกนแบบคีย์บอร์ด) หรือพิมพ์รหัสแล้วกด **Enter** → การ์ดแสดงรูป ชื่อ รหัส ห้อง
3. ตรวจว่าเป็นนักเรียนคนนั้นจริง แล้วกด **Enter** อีกครั้ง (หรือปุ่ม "บันทึกเวลามาถึง")
4. ผลแสดงทันที: ตรงเวลา / มาสาย กี่นาที / เคยบันทึกแล้ว (สแกนซ้ำไม่สร้างรายการใหม่)

- เวลาที่ใช้ตัดสินคือ **เวลาเซิร์ฟเวอร์** ไม่ใช่นาฬิกาเครื่อง
- **แถวรอ**: ถ้านักเรียนต่อแถวรอนาน ใส่ "เวลามาถึงของแถวรอ" ก่อนสแกน เพื่อไม่ให้นักเรียนถูกนับสายเพราะการบันทึกช้า (ระบบบันทึกว่าเป็นเวลาที่ระบุเอง)
- **ค้นหาด้วยชื่อ** ใช้เมื่อไม่มีบัตร; **กล้อง** ใช้ได้เฉพาะเบราว์เซอร์ที่รองรับ (ต้องทดสอบกับอุปกรณ์จริงของโรงเรียน)
- **ออฟไลน์**: เมื่อเชื่อมต่อไม่ได้ ระบบเสนอให้เก็บ "รหัสที่สแกน" ไว้ในเครื่อง (ไม่เกิน 24 ชั่วโมง) — รายการเหล่านี้ **ยังไม่สำเร็จ** จนกว่าจะกด "ส่งรายการออฟไลน์" และเซิร์ฟเวอร์ตรวจผ่าน รายการที่ผิดปกติ (เวลาเครื่องเพี้ยน เกิน 12 ชั่วโมง รหัสไม่พบ) จะเข้างานตรวจสอบ ไม่ถูกบันทึกอัตโนมัติ
- การลงเวลาที่ประตู **ไม่ใช่หลักฐานว่าเข้าห้องเรียน**

## 2. เช็กชื่อประจำวัน (ครูที่ปรึกษา)

1. เลือกห้อง (ห้องที่ปรึกษาขึ้นก่อน) และวันที่ (ย้อนหลังได้ตามค่าตั้ง `attendance.rollcall_backdate_days`, ค่าเริ่มต้น 3 วัน)
2. ตารางแสดงหลักฐานข้างชื่อ: เวลาที่ประตู มาสาย ใบลาที่อนุมัติ ข้อมูลขัดกัน
3. ทุกคนตั้งต้นเป็น **มา** — เปลี่ยนเฉพาะคนที่ ไม่พบตัว / มาสาย / แจ้งลา แล้วกด **ส่งผลเช็กชื่อ**
4. ส่งซ้ำเพื่อแก้ได้จนกว่าจะยืนยัน; ถ้ามีคนอื่นแก้ไปก่อน ระบบแจ้งและโหลดข้อมูลล่าสุดให้ตรวจอีกครั้ง

**ยืนยันขาดเรียน**: หลังส่งผลแล้ว ส่วน "ยืนยันขาดเรียน" แสดงเฉพาะนักเรียนที่ยัง **รอตรวจสอบ** (ไม่มีหลักฐานการมา ไม่มีใบลา) — เลือกเฉพาะรายที่ตรวจสอบแล้วว่าไม่มาโรงเรียน ระบบแจ้งผู้ปกครองว่า "ขาดเรียน" เฉพาะรายการที่ยืนยันเท่านั้น
"ไม่มีข้อมูล" **ไม่ใช่** "ขาด"

**งานตรวจสอบของห้อง** (ใต้ตาราง): ข้อมูลขัดกัน (เช่น ไม่พบตัวแต่มีบันทึกประตู) นักเรียนที่ยังไม่ทราบสถานะ คำขอแก้ไขจากผู้ปกครอง — ปิดงานพร้อมบันทึกสรุปทุกครั้ง

## 3. แจ้งลา

- หนึ่งใบลาต่อนักเรียนหนึ่งคน ระบุ **รายวัน**: ทั้งวัน / ครึ่งวันเช้า / ครึ่งวันบ่าย / บางคาบ (ระบุเลขคาบ)
- ปุ่ม "เพิ่มช่วงวันที่" เติมวันจันทร์–ศุกร์ให้อัตโนมัติ ระบบตรวจวันหยุด วันที่ไม่อยู่ในทะเบียน และวันที่ซ้ำกับใบลาเดิม แล้วแจ้งข้อผิดพลาดรายแถว
- ยื่น **ย้อนหลัง** ต้องระบุเหตุผล (จำนวนวันย้อนหลังสูงสุดตามกฎเส้นทางอนุมัติ)
- เอกสารแนบ ไม่เกิน 3 ไฟล์ ไฟล์ละ 5 MB (PDF/JPG/PNG) — ใบรับรองแพทย์เป็นข้อมูลอ่อนไหว เห็นได้เฉพาะผู้มีสิทธิ์ และทุกการเปิดอ่านถูกบันทึก audit
- ใบลาที่ **นักเรียน** ยื่นต้องให้ผู้ปกครองยืนยันก่อน (ตามกฎตัวอย่าง) แล้วจึงไปถึงโรงเรียน
- สถานะผู้ปกครองยืนยันและสถานะโรงเรียนอนุมัติ **แสดงแยกกัน**
- ก่อนได้ข้อยุติ ผู้ยื่นถอนได้; หลังอนุมัติ ขอยกเลิกได้ (ต้องมีผู้มีอำนาจพิจารณา); ใบลาที่ถูกส่งกลับ กด "แก้ไขและส่งใหม่"
- ร่างใบลาเก็บในหน่วยความจำของแท็บเท่านั้น (ปิดแท็บแล้วหาย) เพื่อไม่ทิ้งข้อมูลนักเรียนไว้ในเครื่องที่ใช้ร่วมกัน

## 4. พิจารณาใบลา

- รายการ "รอฉันพิจารณา" แสดงเฉพาะใบลาที่บัญชีนี้มีอำนาจตามเส้นทาง (ตัวอย่าง: ≤3 วันเรียน → ครูที่ปรึกษา, ≥4 วันหรือกิจกรรมโรงเรียน → กิจการนักเรียน)
- **อนุมัติบางช่วง**: เลือกผลรายวันในตาราง แล้วกด "อนุมัติบางช่วง" (ต้องระบุเหตุผล)
- ไม่อนุมัติ / ส่งกลับ / ยกเลิกโดยผู้มีอำนาจ ต้องมีเหตุผลเสมอ
- กิจการนักเรียน "เปลี่ยนผู้พิจารณา" ได้เมื่อผู้พิจารณาไม่อยู่
- การอนุมัติหรือยกเลิกใบลาที่ครอบคลุมวันที่ผ่านมาแล้ว ทำให้ระบบ **คำนวณการมาเรียนของวันนั้นใหม่** ทันที (รายงานเปลี่ยนตาม)

## 5. ประวัตินักเรียน / การแก้ไขข้อมูล

- สถิติแสดงพร้อม "วิธีนับ" — นิยามเดียวกับรายงาน; หน่วยวัน ครึ่งวัน คาบ แสดงแยก ไม่บวกปน
- ไทม์ไลน์เก็บประวัติทุกรายการ รายการที่ถูกแก้แสดงขีดฆ่า (ไม่ลบ)
- **ครูที่ปรึกษา/กิจการนักเรียน**: "แก้ไขข้อมูลการมาเรียน" — ยกเลิกรายการ, แก้เวลามาถึง, เพิ่มรายการมาถึง, แก้ผลเช็กชื่อ, ยกเว้นการนับสาย — ต้องมีเหตุผล ระบบสร้างรายการใหม่แทนที่ของเดิม คำนวณใหม่ และแจ้งผู้ปกครองเฉพาะเมื่อข้อเท็จจริงที่เคยแจ้งไปเปลี่ยน
- **ผู้ปกครอง/นักเรียน**: "ขอแก้ไขข้อมูลการมาเรียน" — คำขอไปที่งานตรวจสอบของครูที่ปรึกษา ข้อมูลเปลี่ยนเมื่อครูอนุมัติเท่านั้น
- **ข้อยกเว้นการนับสาย** ทั้งกลุ่ม (เช่น รถรับส่งล่าช้า): กิจการนักเรียน ทำที่หน้า "ภาพรวมวันนี้" → เลือกห้อง → เลือกนักเรียนที่มาสาย → เหตุผล ระบบเก็บเวลามาถึงจริงไว้และแสดงผลการยกเว้นแยกต่างหาก

## งานอัตโนมัติ (ตัวตั้งเวลา cronTick)

| งาน | เมื่อ | ทำอะไร |
|---|---|---|
| เปิดวัน (`attendance.openDay`) | หลัง `attendance.open_day_time` (ค่าเริ่มต้น 05:30) วันเรียน | สร้างสถานะเริ่มต้น "รอตรวจสอบ" ของนักเรียนที่อยู่ในทะเบียน (สร้างซ้ำไม่ได้) |
| ตรวจนักเรียนที่ยังไม่ทราบสถานะ | หลัง `verify_after_time` ของกฎ ABSENCE_VERIFICATION | เปิดงานตรวจสอบรายห้องและเตือนครูที่ปรึกษาในระบบ (ไม่แจ้งผู้ปกครองว่าขาด) |
| คำนวณใหม่รายคน/รายวัน | เมื่อกฎหรือข้อมูลย้อนหลังเปลี่ยน | ปรับ DailyAttendance ให้ตรงกับเหตุการณ์ |
