# คู่มือใช้งาน: งานติดตาม การติดต่อ และการแจ้งเตือน (ชุดที่ 4)

> เกณฑ์ทั้งหมดเป็น **ค่าตัวอย่าง** (เช่น สาย 3 ครั้งใน 30 วันเรียน) ไม่ใช่ระเบียบของโรงเรียนจนกว่าจะกำหนดค่าจริงในหน้า "ตั้งค่า"
> ระบบนับข้อเท็จจริงที่นิยามไว้เท่านั้น **ไม่ตัดสินนิสัย ความผิด หรือบทลงโทษ** และไม่ตัดคะแนนอัตโนมัติ

## 1. เรื่องติดตามเกิดขึ้นได้อย่างไร

| ประเภท | เกิดเมื่อ | ผู้รับผิดชอบเริ่มต้น |
|---|---|---|
| สายเกินเกณฑ์ | งานประจำวันหลังเลิกเรียน (`followup.evaluate_time` ค่าเริ่มต้น 16:30) นับ "มาสาย (นับ)" ในช่วงวันเรียนล่าสุดตามกฎ `FOLLOWUP_LATE_COUNT` | ครูที่ปรึกษาของห้องปัจจุบัน (ไม่มี → กิจการนักเรียน) |
| ขาดเกินเกณฑ์ | เช่นเดียวกัน นับ "ขาด (ยืนยันแล้ว)" ตามกฎ `FOLLOWUP_ABSENCE_COUNT` | เช่นเดียวกัน |
| ผู้ปกครองขอให้ติดต่อกลับ | ผู้ปกครองกดปุ่มในแอปหรือใน LINE | ครูที่ปรึกษา (ความสำคัญสูง กำหนด 24 ชม.) |
| ไม่ได้รับการรับทราบตามเวลา | ผู้ปกครองไม่กดรับทราบเรื่องที่กฎกำหนดว่าต้องรับทราบ (เช่น ขาดเรียน) ภายในเวลา | ครูที่ปรึกษา — ให้ติดต่อด้วยช่องทางอื่น |
| เปิดโดยครู | ครูที่ปรึกษา/กิจการนักเรียนเปิดเองจากหน้าประวัตินักเรียน | ผู้เปิด (หรือผู้ที่เลือก) |

**กันเปิดซ้ำ**: แต่ละนักเรียนมีเรื่องจากกฎเดียวกันเปิดอยู่ได้เรื่องเดียว — รันซ้ำหรือรีเฟรชไม่สร้างเรื่องใหม่
**หลังปิดเรื่อง**: มีช่วงพัก (`cooldown_school_days` ค่าตัวอย่าง 10 วันเรียน) และข้อเท็จจริงก่อนวันปิดจะไม่ถูกนับซ้ำ เรื่องใหม่จะเกิดจากเหตุการณ์หลังปิดเท่านั้น

ทุกเรื่องแสดง **เหตุผลที่เข้าเกณฑ์พร้อมรายการอ้างอิง** (วันที่ เวลามาถึง จำนวนนาทีสาย) และระบุว่ากฎเป็นค่าตัวอย่างหรือไม่

## 2. หน้า "งานติดตามและการติดต่อ"

- มุมมอง: เรื่องของฉัน / ทั้งหมดในขอบเขต (ห้องที่ปรึกษา) / เกินกำหนด / ปิดแล้ว
- **ข้อความ/คำขอติดต่อจากผู้ปกครองที่รอตอบ**: ข้อความ LINE จากผู้ปกครองที่ผูกบัญชีแล้ว หรือการติดต่อเข้าที่บันทึกไว้ — กด "โทรกลับแล้ว — บันทึก" เมื่อจัดการแล้ว
- รายละเอียดเรื่อง: เหตุที่เปิด หลักฐาน ผู้ปกครองพร้อมปุ่มโทร (tel:) บันทึกการติดต่อ นัดหมาย และประวัติทั้งหมด

### บันทึกการติดต่อ
- **การกดปุ่มโทรไม่ถือว่าโทรสำเร็จ** ต้องบันทึกผลทุกครั้ง — "ติดต่อไม่ได้" ก็ต้องบันทึก
- ผล "ติดต่อไม่ได้ / ต้องติดตามต่อ / ข้อมูลติดต่อไม่ถูกต้อง" → สถานะ "รอการตอบกลับ"; ผลอื่น → "กำลังดำเนินการ"
- ติ๊ก "ต้องติดตามต่อ" พร้อมวันเวลา → กำหนดเวลาของเรื่องเลื่อนตาม
- บันทึกเท่าที่จำเป็น ไม่ใส่รายละเอียดสุขภาพเกินความจำเป็น

### นัดหมาย / ส่งต่อ / ปิดเรื่อง
- นัดหมาย → บันทึกผล "พบแล้ว / ไม่มาตามนัด / ยกเลิก" (ต้องมีบันทึก)
- ส่งต่อผู้รับผิดชอบได้เฉพาะผู้ที่มีสิทธิ์ดูแลนักเรียนคนนั้น (ครูที่ปรึกษาของห้อง หรือกิจการนักเรียน) พร้อมเหตุผล ผู้รับได้รับแจ้งเตือน
- "บันทึกว่าแก้ไขแล้ว" → รอปิด; "ปิดเรื่อง" ต้องมีข้อสรุป; "เปิดเรื่องอีกครั้ง" ต้องมีเหตุผล
- เรื่องเกินกำหนด: เจ้าของได้รับแจ้งเตือนหนึ่งครั้งต่อกำหนดเวลา

## 3. หน้า "การแจ้งเตือน" (ทุกบทบาท)

- รายการแจ้งเตือนของตนเอง — การเปิดดูคือ "อ่านแล้ว" แต่ **"รับทราบ" ต้องกดเอง**
- ผู้ปกครอง: ปุ่ม **รับทราบ** และ **ขอให้ครูติดต่อกลับ** (สำหรับเรื่องที่เกี่ยวกับบุตรหลาน เช่น ขาดเรียน มาสาย)
- ช่องทาง: แสดงอีเมล (ปิดบังบางส่วน) และสถานะ LINE — เชื่อม/ยกเลิกการเชื่อม LINE ได้เอง (ดูขั้นตอนใน docs/GATEWAY_TH.md §6)

## 4. หน้า "ติดตามการส่งแจ้งเตือน" (ผู้ดูแลระบบ/กิจการนักเรียน)

- สรุปจำนวนตามช่องทางและสถานะ 30 วัน: รอส่ง / กำลังส่ง / รอส่งซ้ำ / **ผู้ให้บริการรับคำขอแล้ว (ไม่ใช่การอ่าน)** / ส่งไม่สำเร็จ / ยกเลิก
- ดูสาเหตุและประวัติการพยายามส่งแต่ละครั้ง (รหัสคำขอของผู้ให้บริการ, HTTP status)
- **ส่งซ้ำแบบเดิม** (LINE เท่านั้น ภายในอายุ retry key): LINE ไม่ส่งซ้ำถ้าเคยรับแล้ว
- **ส่งใหม่**: สร้างข้อความใหม่ — ผู้รับอาจได้รับซ้ำ ต้องระบุเหตุผล (บันทึก audit) อีเมลที่ "ไม่ทราบผล" ใช้ได้เฉพาะทางนี้
- **ยกเลิกการส่ง** รายการที่ยังรอส่ง
- ระบบตรวจสิทธิ์ผู้รับอีกครั้งก่อนส่งทุกครั้ง: ผู้ปกครองที่สิ้นสุดความสัมพันธ์ ปิดการรับแจ้ง หรือยกเลิกช่องทาง จะไม่ได้รับข้อความใหม่ (สถานะ "ยกเลิก" พร้อมเหตุผล)
- ช่วงงดส่ง (ค่าตัวอย่าง 21:00–06:00): ข้อความปกติจะเลื่อนไปส่งหลังช่วงงดส่ง ข้อความเร่งด่วนส่งทันที

## 5. ยังไม่ส่งมอบในชุดนี้

- รายงาน R01–R12 และ PDF/XLSX (ชุดที่ 5)
- คะแนนพฤติกรรม (ปิดโดยค่าเริ่มต้น ต้องมีระเบียบและการอนุมัติก่อน)
- SMS (ไม่มีผู้ให้บริการจริง)
- โหมดที่ GAS ดึง event LINE จาก gateway เมื่อนโยบาย Workspace ไม่อนุญาต "Anyone" (ดู docs/GATEWAY_TH.md §8)
